# 工程工具

可重复使用的工程工具：

- `http_load_generator`：HTTP 压测，输出吞吐和 p50/p95/p99。
- `http_business_load_generator`：商品、库存、活动和监控只读接口压测。
- `flash_sale_soak_test`：本地秒杀流水线长稳样本。
- `mysql_capacity_test`：MySQL 查询并发样本。
- `redis_concurrency_test`：Redis Lua 库存与 Token Bucket 并发验证。
- `rabbitmq_smoke_test`：RabbitMQ 持久化命令、Publisher Confirm、manual ACK 和事件发布验证。
